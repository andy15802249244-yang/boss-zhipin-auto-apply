# BOSS Autoply — Boss直聘自动投递守护进程

> 个人求职提效工具：在指定时间窗内，按"活跃HR优先"策略向 Boss直聘网页版岗位批量发起沟通，
> 带每日预算、风控停车、卡页自愈、进度预测提速与 Windows 弹窗报告。

![status](https://img.shields.io/badge/platform-Windows-orange) ![node](https://img.shields.io/badge/node-%E2%89%A522-green) ![license](https://img.shields.io/badge/license-MIT-blue)

## ✨ 功能特性

| 能力 | 说明 |
|---|---|
| ⏰ 时间窗控制 | 默认 `10:00-11:30` / `14:00-16:30`，窗口外自动休眠值守 |
| 💰 每日预算 | 默认 145（<150 平台上限），110 份时弹窗预警 |
| 🎯 活跃优先 | 只投「刚刚活跃 / 今日活跃 / 回复超快 / 新发岗」，回复率实测 60%+ |
| 🚫 硬门槛过滤 | 标题黑名单（外语/驻外岗）+ 薪资下限过滤 + 跨天永久去重 |
| 🩺 卡页自愈 | `readyState` 检查、CDP 错误重连、8 分钟停滞看门狗 |
| 🚀 进度预测提速 | 预测达不到目标 → 自动缩短间隔 + 启用扩展关键词池 + 弹窗告知 |
| 📣 弹窗报告 | 每波次结束 Windows 置顶弹窗汇报；缺口/风控/掉登录/平台上限即时报警 |
| 🛑 安全停车 | 检测到滑块/安全验证/访问异常/沟通上限提醒 → 立即停车，绝不让账号冒险 |

##  环境要求

- Windows（弹窗依赖 PowerShell）
- [Node.js ≥ 22](https://nodejs.org)（需要原生 `fetch` / `WebSocket`，**零 npm 依赖**）
- Microsoft Edge 或 Chrome（Chromium 内核，通过 CDP 控制）
- 一个已实名认证的 Boss直聘 **求职者账号**，且**已完成在线简历**（平台要求：无在线简历时无法发起沟通）

## 🚀 快速开始

```powershell
# 1. 启动带调试端口的 Edge（首次会打开 Boss直聘，请人工扫码登录一次）
.\start-edge.ps1

# 2. 配置：复制模板后按需修改（不改也能跑，模板即推荐默认值）
copy config.example.json config.json

# 3. 运行（建议挂后台过夜值守，窗口到点自动开跑）
Start-Process node -ArgumentList "zp_daily.js" -WindowStyle Hidden
```

> 💬 **打招呼语**：脚本点击「立即沟通」后，Boss直聘会自动发送**你账号里预设的招呼语**
> （App：消息 → 设置 → 招聘用语，自行配置）。建议写一句含年限+量化亮点的自我介绍，
> 实测带数据的招呼语回复率显著更高。本工具不代发消息内容，也不读取你的简历。

## ⚙️ 配置项（config.json）

| 键 | 默认 | 说明 |
|---|---|---|
| `cdp` | `http://127.0.0.1:9335` | Edge/Chrome 调试地址 |
| `city` | `101280600` | 城市编码（深圳；北京 101010100，上海 101020100，广州 101280100，杭州 101210100） |
| `dailyBudget` | `145` | 每日发送硬顶 |
| `minTarget` | `120` | 每日最低目标，达不到会报警 |
| `windows` | `[["10:00","11:30"],["14:00","16:30"]]` | 投递时间窗 |
| `keywords` / `extraKeywords` | 见示例 | 主关键词池 / 提速后追加池 |
| `titleBlock` | 外语/驻外正则 | 命中即跳过 |
| `salaryMinK` | `6` | 薪资下限（K），低于跳过 |
| `gapSend` / `gapSendFast` / `gapSkip` | 45-95s / 32-60s / 8-20s | 发送后/提速后/跳过后随机间隔 |
| `stallMs` | `480000` | 无成功发送判定停滞的毫秒数 |

## 🧭 工作原理

```
窗口开始 → 关键词轮换拉取职位列表(滚动加载)
  └→ 逐卡：点卡片开右侧面板 → href精确验证 → 读HR活跃标签/薪资/发岗期
       ├ 命中过滤(不活跃/低薪/黑名单/已聊过) → 跳过(8-20s)
       └ 达标 → 模拟阅读停留 → 重新测量按钮 → 真实鼠标事件点击「立即沟通」
            → 三信号轮询确认发送(弹窗/按钮态/聊天框) → 记账(45-95s)
每6单复查风控与平台上限；8分钟无进展触发自愈；
预测打不满 → 自动提速+扩词；波次结束/异常 → Windows 置顶弹窗报告
```

## ️ 常见问题

**Q: 新用户第一次跑，直接弹"需要登录"？** 不会——检测到未登录时会**等待 10 分钟**给你扫码（Edge 窗口内扫码），期间每 30 秒自动重试；超时才停车报警。
**Q: `no page target` 报错？** Edge 没开调试端口或已关闭，重跑 `start-edge.ps1`。
**Q: 一直 SKIP(inactive)？** 正常——过滤器在替你省额度；若整池扫空会等 12 分钟刷新新岗。
**Q: 弹窗不出现？** 报告同时落盘 `reports/`，看文件即可；PowerShell 需允许 `popup.ps1`（脚本已带 `-ExecutionPolicy Bypass`）。
**Q: Boss直聘前端改版了怎么办？** 脚本会自动诊断：页面有职位链接但卡片选择器失效时，弹窗提示"页面结构已变更"并安全退出（exit 4），不会瞎点。按提示更新 `.job-card-wrap` / `a.job-name` / `.job-detail-container` 三个选择器即可。
**Q: 想停掉？** 结束 node 进程即可；已发送的沟通不受影响。
